## ▶️ How to Run

1. Clone or download this repository.
2. Open the required project folder.
3. Compile the `.cpp` file using a C++ compiler.
4. Run the generated program.

Example:

```bash
g++ cgpa.cpp -o cgpa
./cgpa
```
For Windows:

```bash
g++ cgpa.cpp -o cgpa.exe
cgpa.exe
```
